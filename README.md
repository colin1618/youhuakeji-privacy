# 有话可记公开支持页面

此目录只包含用于 GitHub Pages 发布的静态网站，不包含应用源代码或用户数据。

- `index.html`：网站入口
- `privacy.html`：中英文隐私政策
- `support.html`：中英文技术支持与常见问题

发布到 GitHub Pages 后，将隐私政策链接填写到 App Store Connect 的 Privacy Policy URL，将支持链接填写到 Support URL。

联系邮箱 `hi@55lab.top` 与开发团队 `5.5 LAB` 按现有 App 工程资料填写。正式提交 App Store 前，请实际运营方核对政策内容和联系信息。
